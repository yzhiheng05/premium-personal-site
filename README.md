# Premium Personal Site

A React + Vite personal website with Chinese/English content, a polished public site, and a hidden local admin panel.

## Project Structure

- `src/data/defaultSite.ts` - default site content. This is the main file to edit before deployment.
- `src/i18n.ts` - bilingual display logic and fixed UI copy.
- `src/components/public/` - public website components.
- `src/components/admin/` - hidden admin panel and editors.
- `src/styles.css` - global visual styling.
- `public/assets/` - static images used by the site.
- `dist/` - production build output generated by `npm run build`.

English content is stored as the base content in `src/data/defaultSite.ts`. Chinese content is stored in the same file under `translations.zh`.

## Local Development

```bash
npm install
npm run dev -- --port 5173
```

Open `http://127.0.0.1:5173/`.

## Admin Panel

- Entry: click the footer `2026` mark five times, or type `admin` on the page.
- Password: `atelier`
- Admin saves go to the current browser's `localStorage`.

The admin panel is useful for previewing and exporting edits, but it is not a server CMS. After deploying to Netlify, changes saved in one browser will not update the site for other visitors. For production content, edit `src/data/defaultSite.ts`, build, commit, and deploy.

## Netlify Deploy

Connect this GitHub repo to Netlify and use:

- Build command: `npm run build`
- Publish directory: `dist`

No backend or database is required for the current version.
